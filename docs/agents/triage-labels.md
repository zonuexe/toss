# Triage labels

Use these labels when a skill refers to a triage role.

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | A maintainer needs to review the issue. |
| needs-info | needs-info | More information is needed from the reporter. |
| ready-for-agent | ready-for-agent | The issue is fully specified and ready for an agent. |
| ready-for-human | ready-for-human | The issue needs human implementation. |
| wontfix | wontfix | The issue will not be worked on. |
