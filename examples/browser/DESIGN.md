# Browser example design

Native browser defaults are the design tokens: browser-default colors, type,
spacing, focus indicators, and control appearance. The pages use normal document
flow with semantic headings, status/result lists, native buttons, and links.
PASS and FAIL are visible in text and machine-readable `data-status` attributes;
errors use the same visible result surface. The browser controls light and dark
colors, so the example does not force a color scheme.
