# Browser compiler example design

Use native browser defaults for colors, type, spacing, focus indicators, and
controls. Keep the page in normal document flow with semantic labels for both
source fields and the output, a native button, a visible status, and a text-only
generated-code result. The example does not force a color scheme or execute the
generated output. The two text areas may use a small max-width rule so they fit
narrow screens; labels display above their fields. Colors, fonts, controls, and
focus indicators remain browser defaults.
